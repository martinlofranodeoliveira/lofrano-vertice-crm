# Segurança e limites

Esta é uma demonstração estática local. Não há login, controle de acesso, pagamento, agenda real ou armazenamento de dados de clientes. Não use formulários deste protótipo como coleta real sem implementar e validar um backend apropriado.

Ao relatar um problema, forneça exemplo mínimo sintético e não publique dados pessoais, tokens ou credenciais. Não há promessa de prazo de resposta ou certificação de segurança.
