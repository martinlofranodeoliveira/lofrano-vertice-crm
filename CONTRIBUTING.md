# Contribuir

Abra uma issue com objetivo, comportamento observado, versão e passos reproduzíveis. Use dados sintéticos. Para mudanças de código, inclua um teste do comportamento, rode `npm test` e `npm run build` e atualize a documentação. Preserve acessibilidade, responsividade, origem e licenças. Nunca inclua `.env`, chaves ou dados de terceiros.
